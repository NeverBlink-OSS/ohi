## Inherited fields

A class extends the abstract classes and traits of its parent classes and mixins, which declare its fields as `def`s. A subclass's field overrides them, so it keeps the type of its parents' fields where a `slot_usage` would change it:

- A slot that a class makes required keeps the parent's `Option`, `Seq` or `Map`, with a `@required` annotation. Decoding fails when its value is missing or empty.
- The `def` of an inlined class gives the class's trait or abstract class, not its case class, so that a subclass can narrow the range to a subclass.

See [Slots changed by a class](/docs/slot-usage-inheritance/#slots-changed-by-a-class).

## Whole documents

If the tree root has a `tree_root_as` other than `plain`, a document isn't one object. The
output then also has a type for the whole document, named after the schema. For a schema named
`some_schema`:

| `tree_root_as`                 | Document type                                  |
|--------------------------------|------------------------------------------------|
| `optional`                     | `type SomeSchemaDocument = Option[X]`          |
| `list`                         | `type SomeSchemaDocument = Seq[X]`             |
| `compact_dict`, `simple_dict`  | `type SomeSchemaDocument = Map[String, X]`     |

`X` is the class that holds the instances:

- the interface `SomeClass`, if a type designator picks the implementation of each object
- otherwise `SomeClassImpl`, if the tree root has an interface
- otherwise the case class `SomeClass`

An abstract or mixin tree root without a type designator gets no document type, because no codec
can tell which class to read. If another generated type has the same name as the document type,
the document type gets underscores at the end until its name is free, such as `SomeSchemaDocument_`.

Read and write a document with one codec. The generated code needs only the runtime module, but
the codec and YAML parser come from the yaml module, which you add as a dependency:

```scala
import eu.neverblink.linkml.yaml.LinkmlYamlCodec
import org.virtuslab.yaml.{NodeOps, parseYaml}

val codec = LinkmlYamlCodec.derived[SomeSchemaDocument]
val document = codec.decode(parseYaml(text).toOption.get)
val text2 = codec.encode(document).asYaml
```

In the dict forms, the codec reads the key of each object from its dict key. Write documents
with `encode` without `skipId`. With `skipId = true`, an object with a key and one other slot
is written as a bare value, which `compact_dict` doesn't accept.
