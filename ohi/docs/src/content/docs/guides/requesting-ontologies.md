---
title: Request an ontology
description: Ask for an ontology or a new release to be added to ohi.
---

Use the [ontology request form](https://github.com/NeverBlink-OSS/ohi-index/issues/new?template=ontology-request.yml)
to ask for an ontology or a new release to be added to ohi. Include:

- The ontology's name.
- A link to its official website or source repository.
- A version, if you need a particular release.
- What you want to use it for.

You do not need to prepare any files. Keep follow-up information and questions in the same issue.

You may speed up the process of having the ontology added to the index [by packaging it yourself](/docs/guides/contributing-ontologies/).
